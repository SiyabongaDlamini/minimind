# Engineering Handbook

## Code Review Policy
All pull requests require approval from at least one senior engineer before merging.
Automated unit tests must pass with 100% test coverage on critical modules.

## Deployment Guidelines
Production deployments are scheduled every Tuesday at 10:00 UTC.
Emergency rollbacks can be triggered by running the rollback pipeline in CI/CD within 5 minutes.

## Working Hours & Remote Work
Core collaboration hours are between 10:00 and 15:00 local time.
Employees are eligible for full remote work after completing their 90-day onboarding period.
